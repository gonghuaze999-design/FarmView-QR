01定位、受众与核心诉求

大屏是基地对外展示与对内管理的"第一屏"：既要让管理者直观感知基地运行，也要向产业同行与主管部门呈现产业前景。

受众关注点大屏对应设计
基地管理者今日运行是否正常：设备、气象、长势、农事实时运行监测区（设备在线、摄像头、气象、NDVI、虫情）
产业同行模式亮点：罗田标杆模式、数字化手段标杆对比模块（罗田模式数据故事）
主管部门领导产业价值、带动效应、发展前景产业价值区（带动面积、种植户、全产业链、目标阶梯）
v2.0 核心诉求（用户明确）
① 按终端横纵比自适应（iPhone 13 / 华为折叠屏 / iPad / 电脑 / 上墙大屏），默认横屏，小屏大屏都高级、丰富、有科技感、有动效但不杂乱；
② 产量产值与产业价值不直接呈现基地实际运行惨淡数据，改为呈现"标杆 + 目标 + 前景趋势"的产业叙事；
③ 数据按年度，年份切换由年度报告驱动（年度报告更新 → 大屏出现新年度），实时数据走接口自动更新；
④ 色调与软件主色（翠绿）衔接过渡 + 科技感。

02纵横比适配体系（v2.0 核心）

不再按"宽度断点"设计，改按宽高比（AR = 宽÷高）分档，同一套内容自动重排为对应模板。进入大屏默认横屏；检测到竖屏时显示"旋转设备"引导（竖屏降级布局仍可用）。

03色调与视觉体系（v2.0 更新）

深色科技底，翠绿主强调色与软件主色调衔接过渡——软件是暖白+翠绿，大屏是深墨绿+荧光翠绿，同一色相家族，从 App 进入大屏时视觉自然延续。

04指标体系与产业价值叙事（v2.0 核心）

指标分三层：运行层（真实实时）→ 成果层（标杆叙事）→ 价值层（前景叙事）。产量产值产业价值不直接呈现亏损实绩，改以"标杆引领 + 目标阶梯 + 产业前景"的方式表达。

4.1 运行层 — 基地运行监测（真实数据，实时刷新）

模块呈现数据源
设备在线设备 X/Y 在线 + 摄像头 3 路 LIVE 呼吸灯locationList / cameraList（1min）

4.2 成果层 — 产量产值（标杆 + 目标叙事，不呈现亏损口径）

  • 标杆亩产：罗田区域 0.5 吨/亩（金色高亮，"早定植 20 天 + 精细管理"模式标签）——展示最佳实践而非平均值
  • 亩产达成阶梯：2026 实际 250kg → 2027 目标 500–600kg 的三阶阶梯图（上行动画），表达"翻番路径"
  • 产值提升趋势：以标杆亩产 × 基地面积 × 收购价口径绘制的 2026→2027→2028 产业产值增长曲线（展望线用虚线金光）
  • 品质价值：高辣度品质指标（辣度收购价体系 7.5 元/辣度、生物刺激素保辣度、AI 虫情精准防控）作为"品质溢价"叙事
  • 口径标注：小字注明"基于标杆地块与年度目标测算"，不直接罗列亏损数字

05年度机制与数据源（v2.0 新增）

年度切换逻辑（由年度报告驱动）

  • 报告清单 `reports/index.json` 增加字段：{"id","title","type":"annual|其他","year":2026,"file","updated"}
  • 大屏年份列表 = 清单中 type=annual 的报告按 year 去重排序；其他类型报告不影响大屏
  • 年度报告更新（新增/替换某年度）→ 大屏自动出现该年度选项；用户顶部下拉切换年份，默认最新年度
  • 尚无新年度数据时，大屏保持显示上一年底数据（默认行为）

数据分层：年度快照 vs 实时接口

数据来源说明
年度指标（亩产阶梯/产值趋势/产业价值）年度快照文件 /reports/dashboard/2026.json与年度报告同步生成（同一套数据管道），大屏按所选年份加载对应快照，保证跨年口径一致、离线稳定
实时运行（设备/气象/NDVI/虫情/农事）现有 /api 接口不随年份切换（展示"当下"运行状态）；接口地址不变
基地基础信息（地块边界/名称）land/list（缓存）当年最新地块数据
联动闭环
生成年度报告时，同一管道同时产出 `dashboard/{year}.json` 快照并随报告发布 → 大屏年份列表出现新年份 → 用户下拉切换。年度报告未更新 = 大屏停留在上年数据（符合用户要求）。

07动效、刷新与技术方案

动效规范（克制原则）

  • 入场：模块 400ms 上浮淡入，级联 80ms；大屏整体"暗场过渡"入场
  • 持续动效仅 4 类：数字滚动（1.2s）、呼吸灯（2s）、轮播（5s）、产业价值金光流动线（6s 循环）——同屏同时最多 2–3 处动态，避免杂乱
  • 数据更新：数字脉冲高亮 300ms；图表 smooth 过渡
  • 低端设备（≤2GB 内存或省电模式）自动关闭流动线与粒子

刷新策略

数据周期
摄像头状态 / 直播常驻；状态 1min
气象实况 / 气象站5 min
NDVI / 卫星30 min（后端缓存复用）
虫情 / 农事 / 设备10–15 min（后端缓存复用）
年度快照（亩产/产值/价值）按年份加载，切年即换，不轮询

降级：接口失败 → 模块内"数据暂不可用"+ 重试；摄像头离线 → 灰罩占位；快照缺失 → 年份列表不含该年。首屏 `Promise.allSettled` 并行 + 骨架屏。
