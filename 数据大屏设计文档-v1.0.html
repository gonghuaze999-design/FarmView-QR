01定位与目标

一屏看懂基地今日全貌：空间（地图）、画面（摄像头）、环境（气象）、长势（NDVI）、虫情、农事六位一体，科技感强、动态实时，既适合基地现场电视/大屏展示，也适合管理者手机随时查看。

维度设计目标
展示场景① 基地会议室/展厅大屏（电视、投影）② 管理者手机横屏 ③ 平板
视觉风格深色科技风：深墨绿/藏青底 + 荧光绿/天蓝/琥珀多色点缀 + 发光边框；与报告"温暖浅色"形成互补（大屏=夜间监控台，报告=白天文档）
数据实时性关键数据自动刷新（见第 05 节刷新策略），故障降级显示"数据暂不可用"占位
零学习成本扫码即看，无需登录；与现有软件同一域名、同一套数据

3.3 地图模块（核心）

  • 复用年度报告的地块分布图方案：纯空白/浅色底 + 28 块地真实边界 + 区域彩色气泡（大屏版改深色底：地块边线荧光绿、区域色提高饱和度）
  • 叠加 IoT 设备图标（气象站蓝 / 虫情灯紫 / 摄像头红），摄像头图标带"LIVE"角标
  • 交互：点击地块 → 右侧滑出详情（名称/面积/作物/最新 NDVI）；点击设备 → 弹实时数据
  • 自动视野：`setFitView` 按地块范围自适应，罗田片区（南侧）默认缩小全景可见
  • 数据来源：land/list（WKT 边界）+ locationList（设备坐标）+ FarmMonitor NDVI

3.4 摄像头直播模块（用户最常用）

  • 3 路 HLS（萤石云）网格自动播放，复用现有 HlsPlayer（含 WeChat X5 兼容、失败自动重试）
  • 每路叠加：摄像头名 + 在线状态呼吸灯 + 时间戳；离线显示最近画面占位+"设备离线"
  • 点击单路 → 全屏播放（支持横屏、滑动切换下一路）
  • 大屏上 3 路常驻常播；手机竖屏显示 1 路大图 + 左右滑动切换

3.5 气象面板

  • 左侧：新元气象站实时快照（温度/湿度/风速/风向，秒级圆环仪表）
  • 右侧：Open-Meteo 7 日预报（温度区间条 + 降雨概率）
  • 灾害提示：高温 ≥35°C / 暴雨预警红色高亮横幅（呼应 2026 年 8-9 月灾害复盘）

3.6 NDVI 长势模块

  • 全基地 NDVI 曲线（近 30 天，含 8 月高温/9 月降雨事件标注）
  • 分区对比迷你柱状（罗田/新元/关坪…7 区）
  • 右侧轮播最新地块 NDVI 影像（ndvi_field_view 图）
  • 数据来源：FarmMonitor /api/farm-monitor/satellite（缓存 30 分钟）

3.7 虫情面板

  • 三盏虫情灯总量数字 + 本周趋势迷你图
  • 主要害虫 TOP5 排行条（斜纹夜蛾/黏虫等红色高亮）
  • AI 识别图片轮播（原图+标注图自动切换，5s/张）
  • 数据来源：getInsectStatistics + getInsectImages（缓存 10 分钟）

3.8 农事模块

  • 近期农事记录滚动列表（时间+任务+地块，新记录从顶部滑入）
  • 2027 关键节点倒计时：定植窗口、采摘窗口（结合罗田"早定植 20 天"经验）
  • 数据来源：queryWorkTask（缓存 15 分钟）

04动效与交互规范

动效应用位置说明
数字滚动KPI 卡、虫情总量1.2s ease-out，数值更新时脉冲光晕
呼吸灯在线状态点、LIVE 角标2s 周期透明度呼吸，离线灰色静止
图表入场所有 EChartsframer-motion 上浮淡入，级联延迟 80ms
轮播NDVI 影像、虫情图片、农事滚动5s 切换；手动滑动暂停
粒子/流光边框模块卡片边框CSS 渐变流光，桌面大屏开启，低端设备自动关闭
点击反馈地块/设备/摄像头弹层滑出（移动端底部 Sheet，桌面侧边抽屉）

动效原则：克制、有节奏、不影响数据读取。全部动效 ≤1.5s 完成，无无限循环高耗能动画（呼吸灯除外）。

05刷新与降级策略

数据刷新周期实现
摄像头状态 / 直播流常驻；状态 1minHLS 长连接 + 状态轮询
气象实况 / 气象站快照5 minOpen-Meteo + getEnvRecordNow
NDVI / 卫星影像30 min后端缓存直接复用
虫情 / 农事 / 设备 / 地块10–15 min后端缓存直接复用（现有 CACHE_TTL）
KPI（产量等年度口径）静态报告口径常量

降级：接口失败 → 模块内显示"数据暂不可用"+ 重试按钮；连续失败 3 次 → 该模块灰化。摄像头离线 → 最近画面+灰罩。页面级：`Promise.allSettled` 并行加载，首屏骨架屏。

07实施计划

阶段内容验收标准
P1 框架 + KPI/dashboard 全屏路由、深色主题、顶栏时钟天气、6 张 KPI 数字卡、入场动效手机/平板/桌面三端布局正确，KPI 数据与报告一致
P2 地图 + 摄像头地块分布深色版 + 设备标记 + 点击弹层；3 路 HLS 直播网格 + 全屏切换微信内自动播放；点击/滑动交互流畅
P3 气象 + NDVI气象站仪表 + 7 日预报；NDVI 曲线 + 分区对比 + 影像轮播数据 10s 内首屏呈现；灾害提示触发正确
P4 虫情 + 农事 + 打磨虫情排行 + AI 图轮播；农事滚动 + 倒计时；流光边框、轮播、降级完善全部模块无空态裸奔；动效符合规范

每阶段完成后本地验证 + 三端截图，经确认后随软件发布节奏推送 GitHub → 服务器部署。
